AgentPay402 MCP 利用規約

制定日：2026年11月25日

この利用規約（以下「本規約」）は、x402株式会社（以下「当社」）が提供する「AgentPay402 MCP」（以下「本サービス」）の利用条件を定めるものです。本サービスを利用する方（以下「利用者」）は、本規約に同意したうえで本サービスを利用するものとします。本サービスを利用した時点で、本規約に同意したものとみなします。

第1条（定義）

本規約で使う用語の意味は次のとおりです。

  1. 「x402」とは、HTTPの402 Payment Requiredを使い、APIの利用料を1回の呼び出しごとに支払うためのオープンな規格をいいます。
  2. 「seller」とは、x402で有料のAPI等を提供する事業者をいいます。
  3. 「facilitator」とは、sellerの依頼を受けて、x402の支払いの確認とブロックチェーンへの送信を行う事業者をいいます。
  4. 「AIアシスタント」とは、Claudeその他、利用者が本サービスを接続して使う対話型のAIをいいます。
  5. 「ウォレット」とは、利用者が自ら管理する暗号資産ウォレット（Phantom、Rabby、MetaMask等）をいいます。
  6. 「承認リンク」とは、本サービスが支払いごとに発行する、支払い内容の確認と署名のためのページへのリンクをいいます。

第2条（本サービスの内容）

  1. 本サービスは、AIアシスタントからx402に対応したAPIを利用するための機能を、MCP（Model Context Protocol）のサーバーとして提供するものです。主な機能は次のとおりです。
    1. x402に対応したAPIの検索、価格・支払い条件の確認
    2. 支払いの前の確認（利用者が設定した上限、sellerの納品の記録等）と、承認リンクの発行
    3. 利用者がウォレットで署名した取引の確認と、sellerへの送信
    4. 支払いの結果と、APIの応答のAIアシスタントへの返却
  2. 本サービスは、利用者の秘密鍵を預からず、利用者に代わって署名しません。支払いは、利用者が承認リンクを開き、自らのウォレットで署名した場合に限り行われます。
  3. 本サービスは、利用者の資金を預からず、支払いを中継しません。支払いは、利用者のウォレットからsellerが指定する受取先へ、ブロックチェーン上で直接行われます。
  4. 当社は、利用者とsellerとの間の取引の当事者ではありません。APIの内容、品質、提供の有無その他sellerとの取引に関する事項は、利用者とsellerとの間で解決するものとします。

第3条（アルファ版）

  1. 本サービスはアルファ版として提供するものであり、機能、仕様、対応するネットワーク及びウォレットは、予告なく変更、追加又は廃止されることがあります。
  2. 本サービスは開発中であり、不具合を含む可能性があります。利用者は、このことを理解したうえで本サービスを利用するものとします。

第4条（利用料）

本サービスの利用料は、現在無料です。利用料を設ける場合は、事前に当社のウェブサイト等で告知します。なお、sellerに支払うAPIの利用料その他ブロックチェーン上の取引に伴う費用は、利用者の負担とします。

第5条（利用資格・提供地域）

  1. 本サービスは、18歳以上の方に限り利用できるものとします。
  2. 次のいずれかに該当する方は、本サービスを利用できません。
    1. キューバ、イラン、北朝鮮、ウクライナのクリミア・ドネツク・ルハンスク・ヘルソン・ザポリージャの各地域その他、日本、国際連合、米国、英国又は欧州連合の包括的な経済制裁の対象となっている国又は地域に所在し、又は居住する方
    2. 日本、国際連合、米国、英国又は欧州連合の制裁対象者として指定されている方、及びその方が所有し、又は支配する法人その他の団体
    3. 暗号資産又はステーブルコインの取引が法令で禁止されている国又は地域に所在し、又は居住する方
  3. 利用者は、前項のいずれにも該当しないことを表明し、保証するものとします。
  4. 利用者は、VPNその他の手段により、前二項の制限を回避してはなりません。

第6条（利用者の責任）

  1. 利用者は、自らのウォレット、秘密鍵、復元フレーズ等を自らの責任で管理するものとします。
  2. 利用者は、署名の前に、承認リンクに表示される支払い先、金額、ネットワーク、払うウォレット及びAPIを確認するものとします。署名された支払いは、利用者の意思によるものとして扱います。
  3. 利用者は、必要に応じて、接続URLで1回の上限及び24時間の合計上限を設定するものとします。
  4. AIアシスタントは、利用者の依頼に基づいて支払いの依頼を作成します。利用者は、AIアシスタントの判断が誤る場合があることを理解し、承認リンクの内容を確認したうえで署名するものとします。
  5. 利用者は、自らが居住する国又は地域の法令を守って本サービスを利用するものとします。

第7条（ブロックチェーン上の取引）

  1. ブロックチェーン上で行われた支払いは、性質上、取り消し、返金又は変更ができません。当社は、利用者が署名した支払いを取り消し、又は返金する手段を持ちません。
  2. ブロックチェーン、ウォレット、seller又はfacilitatorの不具合、仕様変更、混雑その他当社の管理の及ばない事由により、支払いが行われない、遅れる、又は支払った後にAPIの応答が得られない場合があります。
  3. 本サービスは、支払いの後にブロックチェーン上の送金を確認し、その結果を利用者に示しますが、sellerによる納品を保証するものではありません。

第8条（禁止事項）

利用者は、本サービスの利用にあたり、次の行為をしてはなりません。

  1. 法令又は公序良俗に違反する行為
  2. 犯罪による収益の移転、制裁対象者との取引その他の不正な資金の移動に関わる行為
  3. 第三者のウォレットを無断で使う行為
  4. 本サービスのサーバー又はネットワークに過度の負荷をかける行為、又は本サービスの運営を妨げる行為
  5. 本サービスの不具合を不正に利用する行為、又は本サービスに不正にアクセスする行為
  6. その他、前各号に準ずる行為

第9条（利用の停止）

当社は、利用者が本規約に違反した場合、又は第5条第2項のいずれかに該当すると判断した場合には、事前の通知なく、利用者による本サービスの利用の全部又は一部を停止することができます。
